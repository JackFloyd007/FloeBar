## 密码独立实验

通过系统应用 Info.plist 确认独立 helper 标识为 `com.apple.Passwords.MenuBarExtra`。
临时构建仅加入一个显式测试按钮：检查该 helper 唯一运行、仅排除这个标识，
15秒后关闭实验并恢复。未修改密码内容、权限或系统“显示密码图标”设置。
该按钮在最终源码和安装包中均已移除，最终版本不包含密码白名单例外。

CUA 实测：

1. 激活前系统菜单栏包含 Apple密码钥匙和专注模式。
2. 单独隐藏密码的断言激活后，密码项从 AX 树及菜单栏画面消失；专注模式项也从树中消失。
3. 15秒恢复后，密码、专注模式重新出现，实验开关关闭。
4. 再次测试时点击时钟，随后读到了通知中心窗口，但回读 FloeBar 时断言已失活。
   不能把这次操作算作“私有断言持续激活时，时钟完全兼容”的通过证据；恢复可能由
   应用生命周期变化触发，本次没有充分日志证明具体触发源。也不据此声称时钟必然失效。

结论：密码不是技术上绝对不能隐藏；本次接口能隐藏它。但非目标系统项显示也发生变化，
且持续隐藏期间的系统交互未通过独立验收，因此不开放正式支持，不解除 Apple 全局保护。
没有断言专注模式设置本身被更改，观察仅限其图标/AX节点的显示。

## UI 验收

- 普通模式将 CodexBar 从显示拖入隐藏，出现明确原因提示；确认后仍在显示区。
- 普通模式各项目不再暴露“移至隐藏”；仍保留左右排序及移回显示。
- 实验开关启用后，第三方项目恢复“移至隐藏”，Spotlight、输入法、电池、Wi-Fi 保持限制。
- 最终安装版重启后实验关闭，临时测试入口不存在，布局能力说明及辅助功能提示可见。
- 实验切换期间布局缓存曾按物理位置重新分组；最终重启回到显示8/隐藏7。未进行自动清空或重置布局。
