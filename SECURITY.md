# Security policy

## Supported versions

Security fixes are provided for the latest FloeBar release.

## Reporting a vulnerability

Please use GitHub's private security advisory form:

https://github.com/JackFloyd007/FloeBar/security/advisories/new

Do not open a public issue for a vulnerability that could put users at risk.
Include reproduction steps, affected versions, and the expected impact. The
maintainer will acknowledge a complete report as soon as practical and coordinate
disclosure after a fix is available.
