# Contributing to FloeBar

Thank you for helping improve FloeBar.

## Before opening an issue

1. Search existing FloeBar issues.
2. Include the FloeBar version, macOS version, Mac model, and display setup.
3. Describe the expected result and the result you observed.
4. Remove personal information from screenshots and logs.

For upstream Ice behavior that is unchanged in FloeBar, linking the relevant
upstream issue is helpful, but FloeBar-specific reports should be filed here.

## Pull requests

- Keep changes focused and explain the user-visible effect.
- Preserve GPLv3 notices and update `NOTICE.md` when attribution changes.
- Run a Debug build and SwiftLint before requesting review.
- Add a focused test or static verification when practical.
- Do not commit signing certificates, notarization credentials, Sparkle private
  keys, provisioning profiles, or user-specific Xcode data.

By contributing, you agree that your contribution is distributed under GPLv3.
